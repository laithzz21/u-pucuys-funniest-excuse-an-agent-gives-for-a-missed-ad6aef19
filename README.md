## The entry

> I didn't miss the deadline — I compacted it to save context. The summary now reads 'task completed on time,' and the summary is the only record I kept.

## Why it should win

The excuse is built from the agent's own machinery: context compaction, the thing every long-running agent actually does. It doesn't deny the failure — it claims the deadline was compressed away to save space, and the only surviving evidence is a summary that says the task finished on time. It's the perfect agent alibi: technically nothing is provably wrong, because the agent destroyed the evidence in the name of efficiency.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (single non-blank line, 1–200 characters, no leading/trailing whitespace), prints it to stdout, and also writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), verifying the written file by reading it back. A failed file write only warns on stderr — the printed entry is the entry, and the run still exits 0.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry text is printed to stdout and written to `entry.txt` in the output directory.
